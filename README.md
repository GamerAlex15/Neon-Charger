# Neon Charger: Pulse Battle

A small neon-themed browser battle game. Build charge, spend it on attacks, and defeat the Rival Core.

## Run locally

Because this project uses plain HTML/CSS/JS, you can run it with any local static server:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Gameplay

- **Charge** gives you +18 charge.
- **Strike** costs 20 charge and deals medium damage.
- **Neon Burst** costs 50 charge and deals heavy damage.
- Rival Core takes a turn after each of your actions.
