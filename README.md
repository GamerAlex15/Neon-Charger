# Neon Charger: Street Clash

A neon-themed **two-player physical fighting game** built with plain HTML, CSS, and JavaScript.

## What changed

This version keeps the original neon battle style, but now it's local **Player 1 vs Player 2** (no AI enemy).
Each turn, the active player chooses a physical move:

- **Jab** (cost 10 stamina, light damage)
- **Kick** (cost 20 stamina, medium damage)
- **Combo Rush** (cost 35 stamina, heavy damage)
- **Catch Breath** (+18 stamina)

## Run locally

```bash
python3 -m http.server 4173
```

Then open http://localhost:4173
